  1. In Phantom, add a new account just for the bot (Add / Connect Wallet → Create new account). Don't use your main account.
  2. Send it a small amount: $50–100 of USDC plus about 0.05 SOL for network fees.
  3. In Phantom: Settings → Manage Accounts → the bot account → Show Private Key. Copy it. Never paste it into a chat or website.
  4. In GitHub: add a repository secret named SOLANA_BOT_KEY and paste the key there.
  5. Then add a repository variable named LIVE_TRADING with value dry (practice). Change it to on to trade for real, or off to stop.
